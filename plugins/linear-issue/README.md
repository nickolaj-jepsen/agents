---
tagline: "Turns a thought, or something Claude Code flagged, into a Linear issue you approve before it's filed."
featured: true
requires:
  - "A Linear MCP server, connected and signed in"
order: 1
---

Run `/linear [what to file]` to review a draft. Omit the note to draft from the recent conversation. To draft from a **You should know** card, open **Learn more**, then choose **Linear issue** (usually `3` in the terminal).

Review the fields before choosing **Create** or **Create & open**. In Desktop and VS Code, use **Edit** to change the fields. If an open issue may already cover the problem, choose **Comment on** in the terminal, or open the suggestion and choose **Comment instead** in Desktop or VS Code.

To come back later, press `Esc` to leave the draft above the prompt. Press `8` to reopen it or press `9` twice to discard it. In Desktop and VS Code, use the **Open** and **Discard** buttons instead.
