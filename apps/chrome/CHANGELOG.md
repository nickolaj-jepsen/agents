# Changelog

## [Unreleased]

- The editor's top border carries the session's readings: the share used of the model's window and the window itself, what the session was priced at, how fast the model answered, and the two chips that condense the transcript. The context pill opens pi's session tree.
- At 70 columns the footer keeps the model and the checkout it is working in, with the branch, instead of giving up the folder first.
- Another extension's footer statuses are drawn as one plain line each, with terminal sequences and newlines removed.
- The frame takes a host's own colours, watched providers, router models and short model names from the JSON file `$PI_CHROME_CONFIG`, and reports what in it does not parse.
- A measurement the host cannot give is left out rather than drawn as a zero.
- `waiting` also covers a peer approval another plugin holds for the agent outside any tool call, from the channel the [`claude-peers`](../claude-peers/) plugin publishes.
- A label the frame did not write — another extension's status, a catalogue model name, a provider's display name, the session's own name — loses every C0, DEL and C1 control, not only the terminal sequences a colour or a title uses.
- The checkout's Notes entry points are reachable again: open's folder menu carries the Notes row, and `/open plan` still opens the checkout's notes through the notes plugin.
