Matt Pocock's engineering workflow, as adapted here. The skills share one set of workflow notes (`to-spec` defines them), so a spec, its tickets and the research behind them stay where the next skill looks for them.

Start with `/grill-me` on a plan, then `/to-spec` and `/to-tickets`, and `/implement` one ticket or `/implement-spec` the lot.
